# Maven Publication Output Contract

This contract is derived from the locally cached Maven Central `zemeckis-core:0.14` artifacts and the accepted dependency/tooling updates. Version strings vary per release; coordinates, classifiers, entry categories, and dependency scopes remain stable except for the accepted JSpecify and dependency upgrades.

## Artifact Matrix

| Artifact | Main JAR | Sources JAR | Javadoc JAR | POM |
| --- | --- | --- | --- | --- |
| `zemeckis-core` | required | required | required | required |

The main JAR includes a normalized manifest and `META-INF/LICENSE`. Buildr-specific manifest producer fields and timestamps are not compatibility requirements.

## Main JAR Entries

The `zemeckis-core` main JAR must contain:

- Compiled classes for every production Java type under `zemeckis`, including nested classes.
- The corresponding production `.java` sources, including `package-info.java`, because GWT consumers compile from source.
- `Zemeckis.gwt.xml` and `ZemeckisDev.gwt.xml`.
- `ZemeckisConfig.native.js` and `zemeckis.js`.
- All `META-INF/grim/zemeckis/*.grim.json` files generated by the released Grim 0.09 processor.
- `META-INF/LICENSE` and a normalized manifest.

The release integration test must compare a normalized archive manifest so Bazel's ordinary Java JAR is not mistaken for the source-bearing main JAR required by GWT consumers.

## Sources JAR Entries

The sources JAR must contain every production `.java` source plus the two GWT module files and two JavaScript resources listed above. It must not contain compiled classes.

## Javadoc JAR

The Javadoc JAR must contain generated API documentation for the public `zemeckis` API. Exact JDK-generated support assets and formatting are not stable contract entries. No post-generation Javadoc cleanup is required.

## Distribution Layout, Signatures, and Checksums

The release ZIP stores every primary artifact beneath:

`org/realityforge/zemeckis/zemeckis-core/<version>/zemeckis-core-<version><classifier>.<extension>`

For the main JAR, sources JAR, Javadoc JAR, and POM:

- Include the primary file.
- Include a detached ASCII-armored signature `<file>.asc`.
- Include `<file>.md5` and `<file>.sha1`.
- Include `<file>.asc.md5` and `<file>.asc.sha1` for the detached signature.

The normalized distribution manifest therefore contains 24 files. Release tests compare the relative-path manifest with this matrix and verify every signature and checksum is non-empty.

## Bytecode Contract

Every compiled production class must use Java 17 classfile major version 61.
